# המסע של דרקי – לומדים שחמט

אתר לימוד שחמט לילדים מתחילים, בצורת מסע הרפתקאות במפה עם הדרקון דרקי.

- 23 שלבים: רגלי, צריח, רץ, פרש, מלכה, מלך, שח, הצרחה, חידות מט ומשחקים מול הדרקון
- כוכבים ומעקב התקדמות (נשמרים בדפדפן)
- בלי התקנה ובלי ספריות – HTML, CSS ו-JavaScript בלבד

להרצה מקומית: לפתוח את `index.html` דרך שרת סטטי כלשהו.
